# Flicker Meter

A light flicker analyzer for displays, LEDs, and bulbs.

## Download

Download the latest installer for your platform from the [Releases page](https://github.com/Sundial-Labs/FlickerLabs/releases).

- **macOS**: `FlickerMeter-x.x.x-macOS.dmg`
- **Windows**: `FlickerMeter-x.x.x-Windows.zip`
- **Linux**: `FlickerMeter-x.x.x-Linux.tar.gz`
